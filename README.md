# Future House Prediction

An AI-Driven Real Estate Intelligence Platform for house price prediction, future price forecasting, sentiment analysis, and explainable AI.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router
- Recharts
- Axios
- Lucide React

## Planned Features

- House price prediction
- Future real estate price forecasting
- Locality news and sentiment analysis
- Explainable AI
- Property recommendations

## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

Clone the repository and navigate to the project directory.

```bash
git clone YOUR_REPOSITORY_URL
cd future-house-prediction
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
