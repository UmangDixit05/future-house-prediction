# EstateIQ - AI-Driven Real Estate Intelligence Platform

EstateIQ is a web-based real estate intelligence platform designed to help users explore property prices, understand market trends, and make more informed property decisions. The project focuses on Pune, Maharashtra, with localities such as Hinjewadi, Baner, and Kharadi.

The project aims to combine machine learning-based property price prediction, future price forecasting, locality news, and public sentiment analysis into a single platform.

**Current status:** Frontend prototype under development. Backend APIs and machine learning integration will be implemented by the team.

## Features

### 1. Home
- Introduction to the EstateIQ platform.
- Overview of its core capabilities.
- Navigation to the main sections.

### 2. Property Price Prediction
- Interface for entering property details such as locality, area, and BHK configuration.
- Dedicated section for displaying predicted property prices.
- Designed for integration with a trained machine learning model.

### 3. Future Price Forecasting
- Interface for visualizing historical property price trends.
- Charts and layouts for presenting future price projections.
- Designed to display forecasts generated by the backend.

### 4. Market Insights
- Interface for presenting locality-related news.
- Planned sentiment analysis of public discussions using Reddit data.
- Designed to incorporate external news and sentiment APIs.

> **Note:** Any sample or demonstration values displayed in the frontend are not verified model predictions or live market data.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd future-house-prediction
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal, usually `http://localhost:5173`.

### Production Build

To create a production build:

```bash
npm run build
```

To run the configured lint checks:

```bash
npm run lint
```

## Planned Backend Integration

The frontend is being developed separately so that the backend team can integrate the required data processing and machine learning functionality.

Planned integration includes:

- **Price prediction:** A trained machine learning model that estimates property prices using property attributes and location data.
- **Future forecasting:** Historical data processing and forecasting models to estimate future market trends.
- **Market insights:** News API integration and Reddit-based public sentiment analysis.
- **Data integration:** Backend APIs connecting the frontend with property data, predictions, forecasts, news, and sentiment results.

Actual endpoints, request formats, and response formats will be documented after the backend implementation is finalized.

## Project Goals

- Provide a clean and accessible real estate research interface.
- Present property estimates and market trends in an understandable format.
- Combine property data with locality-level information.
- Create a modular frontend that can be integrated with the team's backend services.

## Project Status

EstateIQ is an academic project prototype. The current focus is on completing the frontend, improving responsive design, and preparing the application for backend and machine learning integration.
